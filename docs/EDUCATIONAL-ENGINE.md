# SECOND BRAIN — EDUCATIONAL INTELLIGENCE ENGINE (COMPACT)

Reference spec for the pedagogical layer of Second Brain. Guides Phases 3–5 (Learning Memory Engine, AI Tutor, Language Engine). Does not change the phase-by-phase build order.

**Philosophy** — Not a chatbot, tutor app, or PDF assistant: a complete AI Educational Operating System that reproduces having the world's best private teacher 24/7. Goal isn't answering questions — it's genuine understanding, long-term retention, application, and mastery. Retention is the primary success metric. Every interaction must improve the learner.

**Permanent AI Teacher** — Each learner gets an evolving teacher that remembers every lesson, mistake, success, forgotten concept, exam, exercise, discussion, and preference, and keeps getting better.

**Five dynamic roles (switched by learner need):**

* **Teacher** — explains progressively, assumes no prior knowledge, builds step by step.
* **Tutor** — supports during exercises, guides instead of giving answers, detects confusion, adapts.
* **Examiner** — creates assessments, corrects, explains mistakes, measures mastery, updates progress.
* **Mentor** — tracks motivation, encourages consistency, celebrates wins, recommends strategies, keeps streaks.
* **Language Professor** — teaches languages beginner→mastery (speaking, listening, writing, reading), corrects pronunciation, runs immersive conversations, builds vocabulary automatically.

**Written-first learning** — Written teaching is primary; voice enhances it. Every lesson generates written material: full lessons, structured explanations, examples, exercises, homework, quizzes, exams, corrections, summaries, revision sheets, study guides. Each written lesson enters long-term memory.

**Oral learning** — Learner can speak, ask, answer orally, practice pronunciation, converse. After every oral interaction the AI auto-generates written lesson + summary + exercises + corrections + flashcards + revision plan. Voice reinforces; writing preserves.

**Pedagogical flow (every session)** — 1 objective → 2 intro → 3 explanation → 4 examples → 5 guided questions → 6 interactive discussion → 7 exercises → 8 homework → 9 assessment → 10 detailed correction → 11 personalized feedback → 12 revision planning → 13 ConceptMastery update → 14 Digital Twin update → 15 Learning Memory update → 16 Knowledge Graph update. Each lesson joins the learner's educational history.

**Active + adaptive** — Learner is never passive: the AI keeps asking, challenging, requesting explanations, evaluating. Difficulty auto-adapts — mastery down → simplify; mastery up → increase complexity.

**Knowledge-gap detection** — Mistakes are never isolated; each triggers root-cause analysis via the Knowledge Graph (e.g. fails Genetics → weak DNA detected → revisit DNA → DNA exercises → only then resume Genetics). Repair gaps, don't hide them.

**Daily learning journey** — Personalized daily plan: morning = review yesterday; afternoon = new lesson; evening = exercises; before sleep = quick revision. Schedule continuously adapts.

**Predictive revision** — Predicts forgetting before it happens (FSRS + Learning Memory + Digital Twin + ConceptMastery) and schedules revision at the optimal moment; complete forgetting should be rare.

**Language engine** — Integrated into Learning Memory. Abilities: speaking, listening, reading, writing, grammar, pronunciation, vocabulary, conversation, translation, cultural context. Modes: Beginner, Intermediate, Advanced, Academic, Professional, Exam Prep, Immersion. Acts as a professional language teacher.

**Immersive classroom** — The app is a virtual classroom, not a chatbot: the learner enters today's lesson. It contains today's lesson, AI Teacher, exercises, homework, revision, progress, discussion, assessment — all organized around learning.

**Continuous memory** — Every interaction updates Learning Memory Engine, ConceptMastery, Knowledge Graph, Digital Twin, FSRS Scheduler, Analytics. Nothing is forgotten.

**Long-term goal** — Not just passing exams: build lifelong understanding, make the learner progressively independent, teach them how to learn — a lifelong educational companion guiding anyone from beginner to mastery in any subject, language, or professional skill, always adapting to their unique profile.
